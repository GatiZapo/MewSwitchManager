# Versioning

MewSwitch Manager uses Semantic Versioning while the project is experimental.

Current line:

`0.2.x-alpha`

Milestones:

- `0.x alpha`: architecture and hardware workflow under active change
- `0.x beta`: feature-complete and focused on reliability testing
- `1.0.0`: stable architecture, tested destructive workflow, installer and release process

Do not call an experimental build `1.0` merely because the UI looks finished.
