# Dependencies

## Required

- Windows 10 1809+ / Windows 11
- Windows PowerShell
- DiskPart
- Administrator privileges
- A USB storage device large enough for the selected Linux image

## Bundled

- .NET 8 runtime (self-contained build)
- SharpCompress 0.50.4 for 7z extraction

## Optional

- WSL. MewSwitch Manager detects it but does not install it automatically by default.

The current USB image workflow does not require WSL.
